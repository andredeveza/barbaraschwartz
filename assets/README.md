# Assets — Bárbara Schwartz

Estrutura central dos ativos visuais do projeto.

## Estrutura

- `renders/` — imagens de projetos, ambientes e visualizações arquitetônicas.
- `brand/` — identidade visual, logotipos, símbolos, fontes e elementos de marca.
- `references/` — referências visuais e materiais usados como pesquisa.
- `press/` — matérias, recortes e registros de imprensa.
- `social/` — capturas e referências de redes sociais.

## Convenção de nomes

Usar nomes descritivos em `kebab-case`, evitando nomes genéricos de câmera/celular.

Exemplo: `quarto-infantil-vista-tv-01.png`.

## Nota

Os renders enviados nesta etapa foram classificados por ambiente e vista. Os arquivos originais devem ser preservados quando possível; versões otimizadas podem ser adicionadas posteriormente para uso web.
